# License decision required before public release

No license has been selected automatically.

This is intentional: choosing a license changes what other people are legally allowed to do with the code and documentation.

Reasonable options include:

- **MIT** — simple, permissive reuse of code;
- **Apache-2.0** — permissive code license with explicit patent terms;
- **no license / all rights reserved** — source is visible, but reuse rights are not granted automatically.

Because this repository mixes code and research documentation, a split licensing scheme is also possible, for example:
- MIT or Apache-2.0 for code;
- CC BY 4.0 for documentation.

Select the license deliberately before switching the final repository to public.
